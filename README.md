# 혼합교통 환경에서 버스 우선 신호(TSP) 효과 분석

## 1. 연구 개요
본 프로젝트는 자율주행차(AV)와 일반 차량(HV)이 혼재하는 교통환경에서 버스 우선 신호(TSP, Transit Signal Priority)의 효과를 분석한다. SUMO 교통 시뮬레이션으로 버스 및 일반 차량의 통행시간 변화를 비교하고, 승객 수를 고려한 통행시간 순편익을 평가한다.

## 2. 실험 구성
- 가로 방향 일반 차량: 100대 또는 200대
- 세로 방향 일반 차량: 60대
- 버스: 5대
- AV 혼합 비율: 0%, 25%, 50%, 75%, 100%
- 실험 반복: 조건별 10개 난수 시드
- 신호정책: BASE(기존 신호), TSP(버스 접근 및 지연에 따른 최대 5초 녹색 연장)
- 기초 실험: 100회 / BASE-TSP 비교실험: 200회

## 3. 통계분석
동일한 교통량·AV 혼합 비율·난수 시드를 사용한 BASE와 TSP를 대응 비교하였다. 조건별 10개의 대응표본을 대상으로 10,000회 부트스트랩 재표본추출하여 평균 효과의 95% 신뢰구간을 추정하였다.

승객 편익은 버스 탑승인원 10명·20명·30명, 승용차 탑승인원 1.3명을 가정하여 사람·초(person-seconds) 단위로 계산하였다. 탑승인원은 관측값이 아닌 가정이다.

## 4. 주요 결과
- 버스 평균 통행시간: TSP 적용 시 조건별 약 13~16초 감소
- 교차 방향 차량: 평균 통행시간이 약 1~3초 증가
- 차량 기준 총 통행시간 순편익: 가로 방향 교통량 100대 조건에서는 불확실, 200대 조건에서는 양수
- 승객 기준 순편익: 버스 탑승인원 10·20·30명을 가정한 30개 세부 조건 모두 평균 및 부트스트랩 95% 신뢰구간 하한이 양수

## 5. 주요 파일
- `experiment_full.py`: AV 혼합 비율별 기초 실험
- `experiment_tsp_full.py`: BASE/TSP 비교 시뮬레이션
- `analysis_full.py`: 기초 실험 분석
- `analysis_tsp.py`: 대응 비교 및 신뢰구간 분석
- `analysis_passenger.py`: 승객 기준 편익 분석
- `sumo/`: 교차로 네트워크 및 버스정류장 설정
- `results/`: 실험 CSV 및 주요 결과 그래프
